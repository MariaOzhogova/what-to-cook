# Что приготовить из того, что есть

Данные для проекта по Python: сайт на Flask, который подбирает рецепты
по продуктам, которые уже есть на кухне.

## Источник

[TheMealDB](https://www.themealdb.com/) — открытая база рецептов с бесплатным
API. Для учебных проектов подходит ключ `1`, регистрация не нужна.

790 рецептов (на 30.10.2026).

## Что в репозитории

- `data/recipes.csv` — сами рецепты.
- `scripts/fetch_data.py` — скрипт, который их скачивает.

## Колонки `recipes.csv`

| Колонка | Что это |
|---|---|
| `id` | номер рецепта в TheMealDB |
| `name` | название блюда |
| `category` | категория: Beef, Chicken, Dessert, Vegetarian и т. д. |
| `ingredients` | ингредиенты с количеством, через `;` |
| `instructions` | как готовить |

Названия и описания на английском, потому что база англоязычная.

## Как обновить данные

Из корня проекта:

```
python3 scripts/fetch_data.py
```
