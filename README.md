# Что приготовить из того, что есть


## Этап 1. Согласование проекта

Выбрала сайт на Flask, который будет показывать рецепты из продуктов есть дома, которые из них можно приготовить. Если для рецепта не хватает пары продуктов, он тоже покажется.

## Этап 2. Данные

Рецепты беру с сайта TheMealDB (https://www.themealdb.com/), у него бесплатный API.
Скрипт scripts/fetch_data.py скачивает рецепты и сохраняет их в data/recipes.csv. Сейчас там 790 рецептов: название, категория, список продуктов и инструкция. 

## Этап 3. Анализ

Анализ данных в файле analysis/analysis.py, там же сохраняются графики. Я посмотрела, сколько продуктов нужно для одного рецепта, какие продукты встречаются чаще всего и сколько рецептов можно приготовить из обычного набора продуктов. Оказалось, что сразу можно приготовить всего 1 рецепт, а если докупить 1-2 продукта, то уже 51. Сайт должен показывать и такие рецепты.

## Как запустить

Нужны библиотеки numpy, pandas, matplotlib и requests. Запускать из папки проекта:

```
python scripts/fetch_data.py
python analysis/analysis.py
```
